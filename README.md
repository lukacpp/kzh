# KZH

An archived Counter-Strike 1.6 movement project for GoldSrc, written in C++. It was developed around 2015–2017 and is preserved here as a historical snapshot.

## What is included

- A configurable bunny-hop module
- Speed and jump-stat HUD rendering
- GoldSrc client, engine, studio, and message hooks
- Runtime cvars for session length, post-command ranges, and ideal-jump limits
- Bundled Valve SDK headers used by the original code

## Building

Open `kzh.sln` in Visual Studio. The project targets Win32 and uses the Visual Studio 2017 toolset (`v141`) with Windows SDK `10.0.15063.0`. A current Visual Studio version may require project retargeting.

## Status

Archived and unmaintained. Its offsets and implementation target older GoldSrc builds, so compatibility with current game versions is not expected.

This repository is provided for historical and educational reference. Use it only in environments where you have permission, and respect game and server rules.
